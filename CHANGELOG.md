# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Command bar UX improvements for faster quick actions and reopen flows.
- Expanded unittest coverage for app state history and regression scenarios.
- GitHub contribution templates for pull requests, bug reports, and feature requests.

### Fixed

- Chart rendering regressions, including heatmap and colorbar behavior.

### Changed

- CI now runs the unittest suite across Windows and Ubuntu on Python 3.9 to 3.12.

## [1.0.0] - 2026-02-12

### Added

- Initial public release of VisuLite Studio.
- Core desktop analytics workflow: data loading, processing, visualization, and export.
